# Travel — подушка для шиї

Односторінковий лендинг товару. Статика: HTML + CSS + JS.

## Як відкрити для друзів (GitHub Pages)

1. На GitHub створіть репозиторій (наприклад `travel-pillow`), **без** README.
2. Завантажте файли (див. команди нижче) або зробіть `git push`.
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / folder `/ (root)` → Save.
4. Через 1–2 хв сайт буде тут:
   `https://derdan22.github.io/travel-pillow/`

## Локально

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер у цій папці.
